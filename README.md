# Nano Stage

Stage-ready mobile controller for the Neural DSP Nano Cortex: landscape editor, live mode, scenes and Bluetooth MIDI footswitch support.

**App:** https://fabiomakino.github.io/nano-stage/

## Como usar
1. Abra o link no **Chrome do Android** (o Safari do iPhone/iPad não tem Web Bluetooth).
2. Feche o app Cortex Cloud (Forçar parada), porque a Nano aceita uma conexão Bluetooth por vez.
3. Toque em **Connect** e escolha a Nano Cortex na lista.

Se o Bluetooth não funcionar, libere "Dispositivos próximos" para o Chrome nas configurações do Android.

## Créditos
Este projeto é baseado no **[Nano Cortex Web Editor](https://github.com/DrD85/nano-cortex-web-editor-with-Fx-Pictures)**, de **DrD85**, distribuído sob a licença MIT. O protocolo Bluetooth descoberto nesse projeto é a base de tudo aqui.

Adições deste projeto: interface para celular na horizontal, modo Palco, cenas, trava dos knobs, suporte aos efeitos do NanOS 2.3, compatibilidade com a AIRSTEP CTX e tipos de capture.

Desenvolvido por Fabio Makino com o Claude (Anthropic).

## Aviso
App independente, sem vínculo com a Neural DSP. Nano Cortex e Neural DSP são marcas da Neural DSP Technologies. Use por sua conta e risco; mantenha backup dos presets no Cortex Cloud.
